# Angler Guide V26

All five reserves and the embedded fish guide from V25, with:
- Metric / Imperial switching
- Celsius / Fahrenheit switching
- All bait and lure preferences
- Fish images and hotspot maps
- Responsive phone layout
- Explicit Vertical / Horizontal layout switch
- Remembers the chosen layout on the device
- Installable PWA files (manifest + service worker)

Open `index.html` in a browser. On supported mobile browsers, serve the folder from HTTPS to use the browser's **Add to Home Screen / Install App** option.
