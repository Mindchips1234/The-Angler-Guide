The Angler Guide icon files

Replace the matching files in the root of your GitHub repository with these:
- favicon.ico
- icon.svg
- icon-192.png
- icon-512.png
- icon-maskable-512.png
- apple-touch-icon.png
- manifest.webmanifest (optional; this file is included as a matching starter manifest)

Note: the original image's solid black background was made transparent. The full logo is fitted inside square icon canvases, so the text may appear small in browser tabs. For the best tiny favicon, a simplified fish/angler-only icon can be made separately.
